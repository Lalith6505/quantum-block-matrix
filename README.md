## 🚀 How to Deploy to GitHub Pages (2-Minute Guide)

### Method 1: Using the GitHub Web Interface (Easiest)
1. Go to [github.com](https://github.com) and log in to your account.
2. Click the **"+"** button at the top right and select **"New repository"**.
3. Name your repository (e.g., `quantum-block-matrix`).
4. Set visibility to **Public** and click **"Create repository"**.
5. On the empty repository page, click **"uploading an existing file"**.
6. Drag and drop all the files and folders from this `github_deploy` folder into the upload box:
   - `index.html` (Main showcase web page with attached Privacy Policy)
   - `privacy.html` (Dedicated standalone Privacy Policy page)
   - `privacy-policy.html` (Alternate URL for Google Play Console compatibility)
   - `assets/` (Icon, Banner, and 6 high-res screenshots)
   - `web_ios/` (Playable mobile Safari web game)
   - `Quantum_Block_Matrix_v1.0.0_Signed.apk` (Direct download link)
7. Click **"Commit changes"**.
8. Go to your repository's **Settings** tab &rarr; Click **Pages** (in the left sidebar).
9. Under **"Build and deployment"** &rarr; **Branch**, select **`main`** (or `master`) and folder **`/(root)`**, then click **Save**.
10. In approximately 60 seconds, your site will be live at:  
    `https://<your-github-username>.github.io/quantum-block-matrix/`
